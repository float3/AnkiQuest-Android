# Ankilope celebration framing

The 336px WebP is exported from the revised `ankilope/celebrate` master in the
server repository. The ear now has clear space above it. Resource names and
companion selection stay unchanged.

[Before/after](review.png) shows the actual Android WebP at 128px and 64px on
light and dark backgrounds. [Hashes](export.json) pin the source PNG and output.
The existing exporter reproduced the WebP byte-for-byte on a second run.
Physical-device checks have not been run.
